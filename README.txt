# Haveli Mysuru — Restaurant Website

A responsive classical Indian restaurant website built from the uploaded Haveli Mysuru menu.

## Included
- Responsive home/hero section with classical Haveli styling
- Full menu transcribed from the uploaded menu pages
- Menu category filters and dish search
- Uploaded menu pages available as original-menu links
- Restaurant gallery
- Table booking form with browser localStorage demo
- Review submission with browser localStorage demo
- Mobile navigation
- No build tools required

## Run
Open `index.html` in a browser.

For a more realistic production version, connect the booking form to a backend/database or a service such as Formspree/Google Apps Script/your own API, and connect reviews to a database.

## Notes
The food photography uses remote Unsplash image URLs. Internet access is needed for those gallery/hero photos; the uploaded menu pages are local assets.
